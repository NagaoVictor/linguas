13\. O número três, o número cinco e o número sete são primos.

14\. Se um número tem mais de dois divisores, ele é composto.

20\. Assumimos inicialmente que existe uma quantidade finita de números primos existentes.

29\. A ordem dos fatores na multiplicação não altera o resultado final.

30\. Por exemplo, o número doze é igual a dois vezes seis.

1\. Os sistemas de numeração são as bases estruturais para representar grandezas quantitativas.

2\. Historicamente, a humanidade desenvolveu sistemas posicionais e sistemas não posicionais diferentes.

3\. O sistema decimal posicional é o mais utilizado na nossa sociedade atual.

4\. Ele utiliza a base dez e dez símbolos distintos chamados algarismos.

5\. O valor de cada algarismo depende diretamente da sua posição relativa.

6\. Contudo, os computadores digitais modernos operam nativamente em uma base binária.

7\. A base binária possui apenas dois estados lógicos estáveis bem definidos.

8\. Estes dois estados discretos são representados digitalmente pelos bits zero e um.

9\. Um bit é a menor unidade de informação armazenada eletronicamente hoje.

10\. Circuitos eletrônicos processam esses bits usando tensões elétricas altas ou baixas.

11\. Outros sistemas matemáticos úteis na computação são o octal e o hexadecimal.

12\. O sistema hexadecimal utiliza a base dezesseis para agrupar quatro bits.

13\. Ele facilita a leitura humana de códigos binários longos e complexos.

14\. A conversão entre bases numéricas segue regras matemáticas de divisões sucessivas.

15\. Para representar números inteiros em computadores, o processo digital é direto.

16\. Entretanto, representar números reais contínuos exige uma abordagem matemática muito diferente.

17\. O conjunto dos números reais é infinito e contínuo entre dois pontos.

18\. A memória física de um computador é inerentemente finita e limitada.

19\. Portanto, é impossível representar todos os números reais com precisão absoluta.

20\. A solução da engenharia para este problema é a representação computacional de ponto flutuante.

21\. Este conceito matemático funciona de forma semelhante à notação científica tradicional.

22\. Um número em ponto flutuante é dividido em três componentes principais.

23\. Estas três partes essenciais são o sinal, a mantissa e o expoente.

24\. O sinal define se a grandeza numérica é positiva ou negativa.

25\. A mantissa contém os dígitos significativos do número real em questão.

26\. O expoente determina a magnitude e desloca a posição do ponto decimal.

27\. A padronização internacional deste sistema é definida pela norma técnica IEEE 754.

28\. A norma estabelece formatos de precisão simples e formatos de precisão dupla.

29\. A precisão simples utiliza exatamente trinta e dois bits de memória total.

30\. Neste formato, um bit é reservado estritamente para o sinal numérico.

31\. Oito bits são alocados para armazenar o valor absoluto do expoente.

32\. Os vinte e três bits restantes contêm a informação detalhada da mantissa.

33\. A precisão dupla expande essa estrutura para sessenta e quatro bits totais.

34\. Ela oferece uma aproximação muito mais exata para cálculos científicos complexos.

35\. Devido à limitação de bits, surge o conceito matemático de arredondamento.

36\. Números como um terço geram dízimas periódicas infinitas na base decimal.

37\. Da mesma forma, o número zero vírgula um possui representação infinita em binário.

38\. Quando truncamos essa dízima, inserimos um erro inevitável no sistema numérico.

39\. A diferença entre o valor real e o valor armazenado é o erro de arredondamento.

40\. Este pequeno erro pode se propagar cumulativamente durante milhares de iterações.

41\. O cálculo numérico estuda métodos para minimizar a propagação desses erros.

42\. Um fenômeno crítico no ponto flutuante é o cancelamento catastrófico.

43\. Isso ocorre ao subtrair dois números muito próximos em magnitude física.

44\. Os dígitos significativos se anulam, deixando apenas ruído numérico no resultado.

45\. Outro problema comum nesta área é o estouro de capacidade do expoente.

46\. O termo overflow ocorre quando o número é grande demais para o limite.

47\. O termo underflow ocorre quando o número é próximo demais de zero.

48\. A norma IEEE 754 define representações especiais como o infinito positivo.

49\. Ela também introduz o conceito de NaN para operações matematicamente indefinidas.

50\. Dominar esses limites numéricos é fundamental para o sucesso do cálculo computacional.

58\. A precisão da máquina é o menor número que somado a um altera o resultado.
